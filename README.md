# Marine Plastic Waste Detection

## Project Overview
This project aims to detect and classify marine plastic waste using machine learning techniques.

## Objectives
- Identify marine plastic waste.
- Classify different types of plastic materials.
- Support environmental monitoring and ocean cleanup efforts.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset Classes
- Plastic Bottle
- Plastic Bag
- Fishing Net
- Foam/Styrofoam
- Clean Water

## Model Workflow
1. Data Preparation
2. Feature Extraction
3. Train/Test Split
4. Model Training
5. Performance Evaluation

## Results
The model was trained to classify marine waste categories and distinguish them from clean water samples.
